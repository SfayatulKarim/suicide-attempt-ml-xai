# Results

This directory distinguishes **historical manuscript-reported results** from results regenerated under the currently installed software environment.

- `manuscript_reported_results.csv` contains the numerical test-set values reported in the manuscript. These values are retained for provenance and are **not** generated by hard-coded values inside the analysis code.
- `cross_validation_results.csv` and `test_set_results.csv` are generated by `src/modeling.py` when the primary pipeline is run.
- `advanced_analysis.py` generates additional current-environment outputs for calibration, bootstrap confidence intervals, sensitivity analyses, ROC/PR curves, and SHAP.

A rerun under a newer XGBoost release produced different XGBoost numerical values from the historical notebook. Therefore, the repository does not claim byte-for-byte reproduction of the historical XGBoost results until the original software environment is identified and pinned.
