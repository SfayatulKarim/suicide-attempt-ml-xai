# Data

## Source dataset

Rahman SA, Anik S, Arifen R, Ahammed S, Islam SM, Islam H. **Behavioral Data-Driven Prediction of Suicide Risk Using Machine Learning Approaches.** Mendeley Data, version 2 (2025). DOI: `10.17632/bpns8vzwrj.2`.

The source dataset is **not redistributed in this repository**. Obtain it from the official Mendeley Data record and place the downloaded file at the repository root as:

```text
original_dataset.csv
```

The raw file should be preserved unchanged as an immutable analysis input. Do not overwrite it during preprocessing.

## Derived files

The canonical preprocessing script generates:

- `cleaned_reproducible_dataset.csv`
- `model_ready_reproducible_dataset.csv`

These derived files are generated locally and are not required to be committed to GitHub.

## Sensitive-data note

The dataset concerns sensitive suicide-related information. Researchers should follow the source dataset's license, attribution requirements, privacy expectations, and their institution/journal's data-governance requirements before redistributing either raw or derived records.
